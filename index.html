Panduan Hubungkan ke Google Spreadsheet

INFO UNTUK GURU:

Untuk menghubungkan ujian ini ke database spreadsheet Anda, tempelkan URL Web App Anda ke dalam kode file HTML ini pada variabel SPREADSHEET_WEBHOOK_URL di dalam tag <script>.

Ikuti langkah-langkah di bawah ini untuk pengaturan Google Spreadsheet Anda:

  1. Buat file Google Spreadsheet baru.
  2. Buat 6 buah kolom dengan header persis seperti ini di Baris 1:
    Nama | Kelas | Benar | Salah | Nilai | Pelanggaran
  3. Klik menu Ekstensi > Pilih Apps Script.
  4. Hapus seluruh kode bawaan yang ada di editor, lalu pastekan kode script di bawah ini:
/* KODE GOOGLE APPS SCRIPT */
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Urutan kolom: Nama, Kelas, Benar, Salah, Nilai, Pelanggaran
    sheet.appendRow([
      data.nama,
      data.kelas,
      data.benar,
      data.salah,
      data.nilai,
      data.pelanggaran
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik tombol Terapkan (Deploy) di bagian kanan atas > Pilih Terapkan baru.
  2. Pilih Jenis: Aplikasi Web (Web App).
  3. Ubah setelan "Yang memiliki akses" menjadi Siapa saja (Anyone).
  4. Klik Terapkan (Deploy), berikan otorisasi akses ke akun Google Anda.
  5. Salin (Copy) URL Aplikasi Web yang dihasilkan.
  6. Buka file HTML ini dengan text editor di komputer Anda, lalu cari variabel const SPREADSHEET_WEBHOOK_URL = "" dan masukkan URL tersebut di dalam tanda kutip.
